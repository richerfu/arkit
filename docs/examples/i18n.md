# i18n

路径：`examples/i18n`

展示 `i18n!` 从 Fluent `.ftl` 生成类型安全 API、`use_i18n_provider` 安装 locale context，以及切换 locale 后的响应式重渲染。macro 支持 select/plural、message/term reference 和 attribute，并在编译期检查所有 locale 的 key 与变量契约。

这个 example 故意把 `arkit` 依赖重命名为 `framework`；它同时验证 `#[entry]` 与 `framework::i18n!` 的展开路径遵循 Cargo rename。
