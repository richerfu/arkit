# Sonner

可堆叠的 Toast 队列，会自动避开安全区，也支持极简样式。

出现和消失走 `AnimatePresence`：新 toast 从锚边滑入并淡入，关闭（计时、滑动或点关闭）时先离场再卸节点。底部锚点向上滑入、顶部锚点向下滑入；退场是同一方向的反向。堆叠里还活着的卡片会立刻补位，正在离场的那张叠在最上面滑走。

折叠和展开按锚边插值位置和宽度（约 400ms）：背面卡片从 14vp 的 peek 扇开到完整间距，宽度从缩放 peek 回到全宽；内容同时淡入淡出。前卡贴着锚边不动。
